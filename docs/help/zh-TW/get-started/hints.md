# 提示面板

[[docker.hints]] 面板會在您使用工具時，說明您正在使用的工具。它一開始就是開啟的，位於 [[docker.properties]] 和 [[docker.objects]] 旁邊；您可以使用 [[menu.help > menu.help.hints]] 或從 [[menu.window > menu.window.dockers]] 再次開啟它。

![提示面板](../../img/get-started-hints.png)

## 面板顯示的內容 {#pages}

- **首頁**會介紹此面板，並列出各種主題，例如繪製線條、形狀、選取、移動和旋轉物件、效果、外框、填色、文字、AI 以及取得說明。每個主題都是一個連結。
- **主題**頁面會說明該主題，並列出相關的工具，每個工具都附有圖示、名稱和用途。按一下工具即可查看其頁面。
- **工具**頁面會告訴您如何使用該工具，每行一個指示，按鍵以粗體顯示，並連結到列出該工具的主題。
- **物件** 頁面會在你選取東西時出現：它會說明你選取的是什麼 (曲線、矩形、文字、點陣圖、群組、裁剪框架、調和、尺度線等，或多個物件)、可以用它做什麼、適用的工具，以及屬性列為它提供的選項。

每個頁面最後都有 [[hint.learn_more]]，這是連到本說明中完整解說該工具或主題之頁面的連結。

## 在頁面之間移動 {#navigation}

當您選擇其他工具時，面板會顯示該工具的頁面。面板底部的列左側有 [[hint.home]]，右側有 [[hint.back]] 和向前，就像網頁瀏覽器一樣。

選取物件會顯示它的頁面；按一下空白處取消選取，就會回到目前工具的頁面。使用繪圖工具繪製時，剛畫好的物件不會切換頁面，工具的頁面會保持顯示；按一下物件即可看到它的頁面。
