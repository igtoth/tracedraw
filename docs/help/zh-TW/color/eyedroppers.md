# 使用滴管複製色彩和屬性

滴管工具會從一個物件取得色彩或一整組屬性，並將其套用到其他物件。兩者都分為兩個步驟，顯示在屬性列上：**選取**（取樣）和**套用**（以樣本上色）。取樣之後，工具會切換為套用；按一下選取按鈕即可再次取樣。<kbd>Esc</kbd> 會捨棄樣本並回到 [[tool.pick]] 工具。

取樣時指標為滴管，套用時為油漆桶。影像即使在群組或框架內也能取色。

## 色彩滴管 {#color-eyedropper}

1. 選擇 [[tool.color_eyedropper]] 工具。
2. 按一下物件以取得其色彩：均勻填色的填滿色彩、漸層的第一個色彩，或外框色彩。在點陣圖上，它會取得指標下方像素的色彩，並依屬性列上設定的樣本大小（1 x 1、2 x 2 或 5 x 5 像素）取平均值。<kbd>Shift</kbd>+按一下會優先取得外框色彩。
3. 按一下物件即可以該色彩填滿它們；<kbd>Shift</kbd>+按一下可為其外框上色（沒有外框的物件會得到一條細外框）。在空的封閉形狀內按一下會將其填滿。

屬性列會顯示取樣的色彩。

移動指標吸取色彩時，指標旁的小框會顯示其下方的色彩：色樣、調色盤色彩或特別色的名稱、在繪圖色彩模式（CMYK 或 RGB）下的數值以及十六進位值。色彩選擇器的滴管也會顯示同樣的小框。

## 屬性滴管 {#attributes-eyedropper}

[[tool.attributes_eyedropper]] 工具可一次將多項屬性從一個物件複製到其他物件。

1. 選擇 [[tool.attributes_eyedropper]] 工具。
2. 在屬性列上選擇要複製的內容：
   - **屬性**：外框、填色和文字（字型、大小和樣式；文字內容本身保留）。預設全部開啟。
   - **變形**：大小、旋轉和位置。預設關閉。
   - **效果**：透明度、下拉式陰影和即時效果。預設關閉。
3. 按一下要複製來源的物件。
4. 按一下每個要複製到的物件。<kbd>Shift</kbd>+按一下則會改為取樣另一個物件。

每次按一下都是一個復原步驟。
