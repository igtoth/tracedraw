# Панели

Панели содержат параметры, которые остаются открытыми во время работы.
Открывайте их через [[menu.window > menu.window.dockers]], их сочетанием клавиш
или кнопкой **+** под вкладками панелей. Открытые панели являются вкладками
вдоль правого края окна (левого в языках с письмом справа налево). На этой
странице перечислены все панели и страницы, которые их объясняют.

## Работа с панелями {#working}

- Щёлкните вкладку, чтобы вывести её панель вперёд; щелчок по передней вкладке
  сворачивает панели.
- Кнопка закрытия в заголовке панели убирает её из вкладок; кнопка сворачивания
  сворачивает область панелей.
- Оставленные открытыми панели вернутся при следующем запуске TraceDraw.
- Сочетания клавиш панелей переключают: нажатие, когда панель впереди,
  скрывает панели.
