# ブラウザー版

> *機械翻訳です。このページは英語版より古い場合があります。*

[TraceDraw は Web ブラウザーで使えます](https://igtoth.github.io/tracedraw/)。何もインストールする必要はありません。デスクトップ版と同じプログラムをブラウザー向けにビルドしたもので、メニュー、ツール、ファイルはすべて同じです。

![ブラウザー版を開いたときに表示されるメッセージ](../../img/get-started-browser-version.png)

## 起動時のメッセージ {#notice}

ページを開くたびに、ブラウザー版はデスクトップ版と同じプログラムであること、そして何が違うかを説明するメッセージが表示されます。[[dialog.ok]] (または <kbd>Enter</kbd>) で閉じます。もう一つのボタンは、デスクトップ版のダウンロードページを開きます。

## デスクトップ版との違い {#differences}

- **速度。** 大きな図面、重い効果、トレース、モザイク、大きなエクスポートは時間がかかり、終わるまでページが応答しなくなります。デスクトップ版は全速で動きます。
- **ファイル。** 開くとインポートにはブラウザーのファイル選択を使い、保存、エクスポート、印刷はファイルのダウンロードになります。ブラウザーはアップロードしたファイルを開き直せないため、最近使った図面は一覧されません。
- **フォント。** ページは自前のフォントを持ち、テキストで必要になったときに初めて追加のフォントを取得します。
- **設定** は、そのコンピューターのそのブラウザーに保存されます。
- **キー。** 図面にフォーカスがある間、プログラムのショートカットはブラウザーではなく TraceDraw に届きます。ただし、クリップボードのキー、再読み込み、ブラウザーの開発者ツールは除きます。<kbd>Ctrl+N</kbd>、<kbd>Ctrl+T</kbd>、<kbd>Ctrl+W</kbd> は常にブラウザーが受け取るので、図面の作成と閉じる操作には [[menu.file]] メニューを使ってください。
- **画面。** マウスとキーボードを使うデスクトップのブラウザーに向いています。タブレットではタッチ用のワークスペースを使ってください ([ワークスペース](../customize/workspaces.md) を参照)。スマートフォンの画面は編集には小さすぎます。
- **マクロ。** マクロ プロジェクトの読み込みと実行はデスクトップ版のみです。
  ブラウザーではマクロのコマンドを選ぶとその旨のメッセージが表示され、
  デスクトップ版のダウンロードへのボタンがあります。
- **更新。** ブラウザー版は常に最新で、インストールするものはありません。自動バックアップとセッションの復元はデスクトップ版の機能です。
  アプリとしてインストールすると、最後に使ったバージョンのまま動き、すべてのウィンドウを閉じた後の次回起動時に新しいバージョンになります。[タブレットと Android アプリ](tablets-and-android.md)を参照してください。
- **筆圧。** ペンはマウスとして使えますが、ブラウザーは筆圧を渡さないため、線の幅は一定になります。
