# カラーパレット

ウィンドウの下に沿って並ぶカラーパレットは、オブジェクトに色を付ける最も手早い方法です。その下の **ドキュメントパレット** には、図面で使っている色が集められます。ほかのパレットを開いたり、自分のパレットを作って編集したりもできます。

## パレットを使う {#using}

| 操作 | 結果 |
|---|---|
| 色をクリック | 選択範囲を塗りつぶします (何も選択していないときは、新しいオブジェクトの塗りつぶしを設定します) |
| 色を右クリック | 選択範囲のアウトラインに色を付けます |
| <kbd>Ctrl</kbd>+色をクリック | その色の 10 分の 1 を選択範囲の塗りつぶしに混ぜます |
| 色を長押し | その色の明るい、暗い、くすんだ、鮮やかな濃淡を表示し、そこから選べます |
| 色をオブジェクトにドラッグ | オブジェクトを塗りつぶします。端にドロップするとアウトラインに色を付けます |
| 斜線の入った枠をクリック | 塗りつぶしを取り除きます (右クリック: アウトライン) |

両端の矢印でパレットをスクロールし、右端のボタンですべての色を一度に表示します。色にポインターを合わせると、その名前と値が表示されます。左端のパレットメニューボタンでパレットのメニューが開きます。

パレットは、点線のつまみでドラッグして、ウィンドウの別の端に移動したり、フローティングにしたりできます。

各辺で、ウィンドウの端か、図面の横 (図面とその側のパネルやツールボックスの間) に置けます。ドラッグ中は青い帯が置かれる場所を示します。グリップを右クリックすると、一覧から場所を選べます。

## ドキュメントパレット {#document-palette}

オブジェクトに適用した色はすべてドキュメントパレットに加わり、図面と一緒に保存されます。そのスポイトはポインターの下の色を追加します。メニューには **自動更新** (色が自動的に追加されないようにします)、**選択範囲から追加**、**ドキュメントから追加**、**色を削除**、**パレットをリセット** (図面がまだ使っている色だけを残します) があります。色やオブジェクトをドラッグして追加することもできます。表示または非表示にするには、[カスタマイズのオプション](../customize/customization.md#color-palette) を参照してください。

## パレットパネル {#palettes-docker}

[[docker.palettes]] パネルには、持っているパレットが、それぞれの色数とともに一覧されます。[[menu.window > menu.window.color_palettes > menu.window.palette_manager]] で開きます。

![パレットパネル](../../img/color-palettes.png)

- パレットにチェックを付けると、描画ウィンドウの下に表示されます。
- [[docker.edit]] は、パレットをパレットエディターで開きます。
- [[menu.window.palette_open]] は、パレットファイル (`.tdpal`、`.gpl`、`.ase`、`.aco`) を開きます。
- [[menu.window.palette_from_document]] と [[menu.window.palette_from_selection]] は、図面または選択範囲で使っている色からパレットを作ります。
- 下部にはドキュメントパレットの色が表示されます。クリックすると選択範囲を塗りつぶし、右クリックするとアウトラインに色を付けます。

## パレットを編集する {#palette-editor}

[[menu.window > menu.window.color_palettes > menu.window.palette_editor]] でパレットエディターが開きます。

![パレットエディター](../../img/color-palettes-palette-editor.png)

1. 編集する [[dialog.palette]] を選ぶか、[[dialog.new_palette]] をクリックして新しく始めます。
2. [[dialog.name]] を入力します。
3. 色をクリックして選択します。[[dialog.add_color]] は現在の色を追加し、[[dialog.remove_color]] は選択した色を削除します。
4. [[dialog.save_palette]] をクリックしてファイルとして保存します。
5. [[dialog.close]] をクリックします。

組み込みのパレットは編集できません。新しいパレットを作るか、コピーを編集してください。
