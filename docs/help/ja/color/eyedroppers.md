# スポイトで色と属性をコピーする

スポイトツールは、あるオブジェクトから色、または属性のセット全体を取り、ほかのオブジェクトに与えます。どちらもプロパティバーに表示される 2 段階で動作します: **選択** (サンプルを取る) と **適用** (それで塗る) です。サンプルを取ると、ツールは適用に切り替わります。もう一度サンプリングするには選択ボタンをクリックします。<kbd>Esc</kbd> はサンプルを破棄して [[tool.pick]] ツールに戻ります。

サンプリング中のポインターはスポイト、適用中は塗りつぶしバケツです。画像はグループやフレームの中でも色を取れます。

## カラースポイト {#color-eyedropper}

1. [[tool.color_eyedropper]] ツールを選びます。
2. オブジェクトをクリックしてその色を取ります: 単色塗りつぶしの色、グラデーションの最初の色、またはアウトラインの色です。ビットマップでは、ポインターの下のピクセルの色を、プロパティバーで設定したサンプルサイズ (1 x 1、2 x 2、5 x 5 ピクセル) で平均して取ります。<kbd>Shift</kbd>+クリックすると、アウトラインの色を優先して取ります。
3. オブジェクトをクリックすると、その色で塗りつぶします。<kbd>Shift</kbd>+クリックすると、アウトラインに色を付けます (アウトラインのないオブジェクトには細いアウトラインが付きます)。何もない閉じた図形の内側をクリックすると、それを塗りつぶします。

プロパティバーには、サンプリングした色が表示されます。

色を取るためにポインターを動かしている間、その横の小さな枠にポインターの下の色が表示されます: 見本、パレットの色または特色の場合はその名前、図面のカラーモード (CMYK または RGB) での値、16 進値です。カラーピッカーのスポイトも同じ枠を表示します。

## 属性スポイト {#attributes-eyedropper}

[[tool.attributes_eyedropper]] ツールは、複数のプロパティをあるオブジェクトからほかのオブジェクトへ一度にコピーします。

1. [[tool.attributes_eyedropper]] ツールを選びます。
2. プロパティバーで、コピーするものを選びます:
   - **プロパティ**: アウトライン、塗りつぶし、テキスト (フォント、サイズ、スタイル。テキストの内容はそのままです)。最初はすべてオン。
   - **変形**: サイズ、回転、位置。最初はオフ。
   - **効果**: 透明度、ドロップシャドウ、ライブ効果。最初はオフ。
3. コピー元のオブジェクトをクリックします。
4. コピー先の各オブジェクトをクリックします。<kbd>Shift</kbd>+クリックすると、代わりに別のオブジェクトをサンプリングします。

クリックごとに元に戻す操作 1 回分になります。
