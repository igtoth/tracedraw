# Comandos dos menus

Esta página lista os comandos de todos os menus, na ordem dos menus, com a página
que explica cada um. Os comandos que precisam de um desenho ficam esmaecidos
enquanto só a Tela de boas-vindas está aberta. Os menus podem mostrar os seus
próprios atalhos; veja
[Opções de personalização](../customize/customization.md#commands).
