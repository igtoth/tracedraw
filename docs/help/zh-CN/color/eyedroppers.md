# 使用滴管复制颜色和属性

滴管工具从一个对象获取颜色或一整套属性，并将其赋予其他对象。两种工具都分两步进行，显示在属性栏上：**选择**（取样）和 **应用**（用样本着色）。取样后，工具切换为应用；单击选择按钮可再次取样。<kbd>Esc</kbd> 丢弃样本并返回 [[tool.pick]] 工具。

取样时指针为滴管，应用时为油漆桶。图像即使在群组或框架内也能取色。

## 颜色滴管 {#color-eyedropper}

1. 选择 [[tool.color_eyedropper]] 工具。
2. 单击对象以获取其颜色：均匀填充的填充颜色、渐变的第一种颜色或轮廓颜色。在位图上，它获取指针下像素的颜色，并在属性栏设置的取样大小（1 x 1、2 x 2 或 5 x 5 像素）范围内取平均值。<kbd>Shift</kbd>+单击优先获取轮廓颜色。
3. 单击对象用该颜色填充它们；<kbd>Shift</kbd>+单击为其轮廓着色（没有轮廓的对象会得到一条细轮廓）。在空的闭合形状内部单击会填充它。

属性栏显示取样的颜色。

移动指针吸取颜色时，指针旁的小框会显示其下方的颜色：色样、调色板颜色或专色的名称、在绘图颜色模式（CMYK 或 RGB）下的数值以及十六进制值。颜色选择器的吸管也会显示同样的小框。

## 属性滴管 {#attributes-eyedropper}

[[tool.attributes_eyedropper]] 工具一次将多项属性从一个对象复制到其他对象。

1. 选择 [[tool.attributes_eyedropper]] 工具。
2. 在属性栏上选择要复制的内容：
   - **属性**：轮廓、填充和文本（字体、大小和样式；文本本身保持不变）。起初全部打开。
   - **变换**：大小、旋转和位置。起初关闭。
   - **效果**：透明度、阴影和实时效果。起初关闭。
3. 单击要从中复制的对象。
4. 单击要复制到的每个对象。<kbd>Shift</kbd>+单击则改为对另一个对象取样。

每次单击为一个撤消步骤。
