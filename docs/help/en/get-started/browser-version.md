# The browser version

You can [use TraceDraw in a web browser](https://igtoth.github.io/tracedraw/)
with nothing to install. It is the same program as the desktop version,
built for the browser, so the menus, tools and files are the same.

![The message shown when the browser version opens](../../img/get-started-browser-version.png)

## The message at start {#notice}

Each time the page opens, a message explains that the browser version is the
same program as the desktop one, and what differs. [[dialog.ok]] (or
<kbd>Enter</kbd>) closes it; a second button opens the downloads of the
desktop version.

## What differs from the desktop {#differences}

- **Speed.** Large drawings, heavy effects, tracing, mosaics and big exports
  are slower, and keep the page busy until they finish. The desktop version
  runs at full speed.
- **Files.** Opening and importing use the browser's file picker; saving,
  exporting and printing download a file. Recent drawings are not listed,
  because a browser cannot reopen an uploaded file.
- **Fonts.** The page brings its own fonts and fetches more the first time
  your text needs them.
- **Settings** are kept in that browser on that computer.
- **Keys.** While the drawing has the focus, the program's shortcuts reach
  TraceDraw instead of the browser, except the clipboard keys, reload and
  the browser's developer tools. <kbd>Ctrl+N</kbd>, <kbd>Ctrl+T</kbd> and
  <kbd>Ctrl+W</kbd> always stay with the browser, so use the [[menu.file]]
  menu to create and close drawings.
- **Screens.** It suits a desktop browser with a mouse and keyboard. On a
  tablet, install it as an app and use the Touch workspace (see
  [Tablets and the Android app](tablets-and-android.md) and
  [Workspaces](../customize/workspaces.md)); a phone screen is too small for
  editing.
- **Macros.** Macro projects load and run in the desktop version only. In
  the browser, every macro command shows a message saying so, with a button to
  the desktop downloads.
- **Updates.** The page is always the latest version; there is nothing to
  install. Installed as an app, it keeps the version you last used and
  takes a new one the next time it starts after all its windows were
  closed.
- **Unsaved drawings.** Closing or reloading the tab, or leaving the
  page, with unsaved changes asks first with the browser's own question.
  Auto-backups are kept in the browser's storage for the site, and the next
  visit offers what a closed, reloaded or crashed tab left, as the desktop
  version does after a crash (see
  [Auto-backup and recovery](open-and-save.md#recovery)). Clearing the
  site's data removes them.
- **Pen pressure.** A pen works as a mouse, but the browser does not pass
  its pressure on, so strokes have an even width.
