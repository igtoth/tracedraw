# Global options

[[menu.tools > menu.tools.options > menu.tools.options_global]] holds the
settings that apply to the whole program: language, printing and export
defaults, tracing, messages and where files are kept.

## General {#general}

![The General page of the global options](../../img/customize-global-options-general.png)

- [[options.language]]: the language of the interface. This Help opens in the
  same language.
- [[options.check_updates]] (on): see
  [Checking for updates](../welcome/about-and-updates.md#updates).
- [[options.agents]]: [[options.mcp_window]] lets AI assistants on this
  computer edit the open drawing; see [Scripts](scripts.md#mcp).
- [[options.reset_all]]: see [Resetting settings](reset-settings.md).

## Printing {#printing}

![The Printing page of the global options](../../img/customize-global-options-printing.png)

[[options.print_starts_with]]: [[dialog.fit_to_page]],
[[dialog.separations]], [[dialog.print_bleed]], [[dialog.crop_marks]],
[[dialog.registration_marks]], [[print.color_bars]], [[print.densitometer]],
[[print.page_info_mark]] (all off), the [[print.sheet]], [[print.landscape]]
and the [[print.gutter]] (5 mm). [[options.print_remember]] keeps the choices
of the last print. Under [[options.print_checks]],
[[options.print_preflight]] (on). See [Printing a drawing](../printing/print.md).

## File Formats {#file-formats}

![The File Formats page of the global options](../../img/customize-global-options-file-formats.png)

- [[options.export_starts_with]]: the [[dialog.format]] (SVG), the
  [[dialog.resolution]] of bitmap formats (300 dpi), the [[dialog.quality]] of
  JPEG and WebP (90), [[dialog.transparent_background]] (on), the
  [[dialog.pdf_standard]], the [[dialog.output_condition]] and the
  [[dialog.bleed]]. [[options.export_remember]] keeps the choices of the last
  export.
- [[options.import_section]]: [[options.import_place]]
  [[options.import_as_in_file]] (at first) or [[options.import_view_center]].
- [[options.cdr_save_section]]: the [[dialog.cdr_version]] new drawings are
  saved in as `.cdr`.

## Bitmap Tracing {#bitmap-tracing}

![The Bitmap Tracing page of the global options](../../img/customize-global-options-bitmap-tracing.png)

[[options.quick_trace_with]] one of the presets (Clipart at first).
[[options.trace_starts_with]] [[dialog.remove_background]] (on) and
[[dialog.delete_original]] (off). See [Tracing bitmaps](../bitmaps/tracing.md).

## Warnings {#warnings}

![The Warnings page of the global options](../../img/customize-global-options-warnings.png)

[[options.warnings_show]] [[options.warn_unread_objects]],
[[options.warn_missing_fonts]] and [[options.warn_shelf_remove]] (all on). Each
message also has a box that stops it; tick the option here to see it again.

## File Locations {#file-locations}

![The File Locations page of the global options](../../img/customize-global-options-file-locations.png)

Shows where the preferences and the auto-backups are kept. The preferences
are in a `tracedraw-settings` folder next to the program when there is one
(a portable copy), otherwise in your system's place for program settings; the
browser version keeps them in the browser.
