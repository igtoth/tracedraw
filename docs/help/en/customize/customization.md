# Customization options

[[menu.tools > menu.tools.options > menu.tools.options_customization]] sets the
look of the interface, your own keyboard shortcuts, which bars show and how
the color palette behaves.

## Appearance {#appearance}

![The Appearance page of the customization options](../../img/customize-customization-appearance.png)

- [[options.center_dialogs]]: dialog boxes open in the middle of the window;
  off, they open where you left them.
- [[options.ui_shadows]] (fewer shadows help slower graphics).
- [[options.colored_icons]]: each group of tools gets a color of its own.
- [[options.ui_size]]: how large menus, bars, icons and panels are, relative
  to the scaling your system gives the monitor (100% at first).
  [[options.reset_to_default]] goes back to 100%. The interface size never
  changes the size of your drawing. [[options.follow_text_size]] makes it
  grow with the desktop text size.
- [[options.color_section]]: the [[options.theme]] (Light, Medium Light,
  Medium Dark, Dark or High Contrast), [[options.follow_high_contrast]], and
  the [[options.desktop_color]] around the page. The button at the right end
  of the status bar switches between light and dark.

## Commands {#commands}

![The Commands page of the customization options](../../img/customize-customization-commands.png)

The page lists every command of the menus, with its shortcut, and the tool
keys. Type in [[options.find_command]] to filter the list.

To give a command your own shortcut:

1. Click the command's shortcut button.
2. Press the keys, such as <kbd>Ctrl+Alt+K</kbd>. <kbd>Esc</kbd> stops waiting.

Your shortcuts come before the built-in ones: when you take a key another
command uses, the page says which command lost it. The menus show your
shortcut. The **x** beside a shortcut removes it, and resetting to the
defaults removes them all. Tool keys are a letter or <kbd>Shift</kbd> and a
letter. See [Keyboard shortcuts](../reference/keyboard-shortcuts.md).

A command can have several shortcuts: a new key joins the ones it has (a
built-in key keeps working beside it), and each key has its own delete
button. The buttons of the bars that run a menu command (New, Open, Save,
Undo, Zoom In and others) take shortcuts too, the same keys as their menu
command, and so do rows the menus show only at times (such as Finish Editing
Contents). A **Toolbar buttons** list holds every button of the Standard and
Zoom toolbars: drag a button you removed from a bar back onto it from there.
