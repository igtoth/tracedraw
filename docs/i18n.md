# User interface languages

TraceDraw ships its interface in the twelve languages below. English is
the source language; every other file is a translation of `en.toml`.

| Code | Language | File |
|---|---|---|
| en | English | `apps/tracedraw/lang/en.toml` |
| zh-CN | Chinese (Simplified) | `zh-CN.toml` |
| hi | Hindi | `hi.toml` |
| es | Spanish | `es.toml` |
| fr | French | `fr.toml` |
| ar | Arabic | `ar.toml` |
| bn | Bengali | `bn.toml` |
| ru | Russian | `ru.toml` |
| pt-BR | Portuguese (Brazil) | `pt-BR.toml` |
| id | Indonesian | `id.toml` |
| de | German | `de.toml` |
| ja | Japanese | `ja.toml` |

## How it works

- Strings are looked up by key with `tr("menu.file.open")`. Keys are
  dotted paths: `menu.*`, `tool.*`, `docker.*`, `dialog.*`, `status.*`,
  `hint.*`, `fill.*`, `outline.*`, `effect.*`.
- Missing keys fall back to English, and a debug build logs them once.
- Placeholders use `{name}`: `"{count} objects selected"`.
- Shortcuts are not translated; they are rendered from the key binding.
- The language is chosen in Options > Workspace > Language, defaults to
  the system locale, and applies without restart.
- Right-to-left (Arabic) flips the docker and toolbox sides and text
  alignment in dockers; the canvas and rulers do not flip.
- Fonts: the UI font is a system font chosen per script (Noto family
  when present) so every language renders without tofu.

## Rules

- No user-visible literal strings in `apps/`; `cargo test` includes a
  check that greps for `ui.label("` and `ui.button("` with literals.
- Add the English key first, then all eleven translations in the same
  commit. Machine translation is acceptable for a first pass; mark the
  line with `# mt` so native review can find it.
