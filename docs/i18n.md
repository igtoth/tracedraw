# User interface languages

TraceDraw ships its interface in the twelve languages below. English is
the source language; every other file is a translation of `en.toml`.

| Code | Language | File |
|---|---|---|
| en | English | `apps/tracedraw/lang/en.toml` |
| zh-CN | Chinese (Simplified) | `zh-CN.toml` |
| hi | Hindi | `hi.toml` |
| es | Spanish | `es.toml` |
| fr | French | `fr.toml` |
| ar | Arabic | `ar.toml` |
| bn | Bengali | `bn.toml` |
| ru | Russian | `ru.toml` |
| pt-BR | Portuguese (Brazil) | `pt-BR.toml` |
| id | Indonesian | `id.toml` |
| de | German | `de.toml` |
| ja | Japanese | `ja.toml` |

## How it works

- Strings are looked up by key with `tr("menu.file.open")` and
  `trf("status.exported", &[("path", p)])`. Keys are dotted paths:
  `menu.*`, `context.*`, `tool.*`, `toolbar.*`, `docker.*`, `dialog.*`,
  `options.*`, `status.*`, `hint.*`, `fill.*`, `transparency.*`, `kind.*`,
  `welcome.*`, `doc.*`. About 1,350 keys per language.
- Files are flat `key = "value"` TOML, embedded in the binary with
  `include_str!`; a test (`i18n::tests::every_language_covers_english_keys`)
  fails the build when a language misses a key.
- Missing keys fall back to English at run time.
- Placeholders use `{name}`.
- Shortcuts are not translated; they are rendered from the key binding.
- The language is chosen in Options > Workspace > Language, defaults to
  the system locale (`LC_ALL`, `LANG`), and applies without restart.
  Default names of new documents, pages and layers follow the language.
- Right-to-left (Arabic) moves the docker column to the left side; text
  in menus and dockers is shaped by the font. The canvas and rulers do
  not flip.
- Fonts: the bundled UI font covers Latin, Greek and Cyrillic. At start-up
  the app registers system fonts as fallbacks per script (Noto Sans
  Arabic / Segoe UI / DejaVu Sans; Noto Sans Devanagari / Nirmala UI;
  Noto Sans Bengali; Noto Sans CJK SC and JP / Microsoft YaHei / Meiryo /
  PingFang) so every language renders without tofu on Windows, macOS and
  common Linux installs. `theme::install_fallback_fonts` has the lists.

## Rules

- No user-visible literal strings in `apps/`, except unit abbreviations,
  file-format names, paper sizes and proper nouns.
- Add the English key first, then all eleven translations in the same
  commit. Machine translation is acceptable for a first pass; mark the
  line with `# mt` so native review can find it. All current files have
  zero `# mt` lines.
- Terminology follows the localised versions of mainstream graphics
  software for each language (for example: Soldar / Souder / Verschmelzen /
  焊接 for Weld; Silueta / Projection / Kontur / 轮廓图 for Contour).
